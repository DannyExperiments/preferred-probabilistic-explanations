Which explanations beat the fallback?

One point belongs to the fallback s. Each other point makes exactly one selector false. Every point has mass 1/5.

Observation used in this example

The observation is true if s or the guard u is true. Otherwise each pair must be covered, and either some pair is doubled or the truth assignment has x₁ true and x₂ false. Choosing ai encodes xi true, while choosing bi encodes xi false if exactly one per pair stays true.

All five supported valuations have u true. Classical entailment still checks valuations with u false. A term with no surviving support fails the positive-probability condition, even when its literals entail the observation.
